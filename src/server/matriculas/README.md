# matriculas

Acceso a cursos por email (invitación o compra) y ruta personal del alumno (`modulo_principal_id`, `orden_modulos`). La matrícula por compra solo la crea el módulo de pagos desde el webhook.

- **Tablas:** matricula
- **Endpoints:** `GET /api/yo/cursos`, `POST /api/cursos/:id/invitaciones`

Patrón y reglas: [docs/arquitectura.md](../../../docs/arquitectura.md).
